# Kutukov Business Landing

Статическая вёрстка лендинга A-Warehouse (главная + тарифы) по макетам Figma.

## Открыть локально

Открой HTML-файл в браузере (двойной клик или Live Preview):

- [pages/index.html](pages/index.html) — главная
- [pages/tariffs.html](pages/tariffs.html) — тарифы

Либо из корня репозитория:

```bash
python -m http.server 8080
# затем http://localhost:8080/pages/index.html
```
